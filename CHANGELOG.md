## [1.0.0] - 2026-09-22

### Added
- **Native Floating UI**: Windows 11 `Win + V` inspired acrylic glassmorphic interface with Ubuntu Yaru Dark/Light design.
- **SQLite Engine with FTS5**: Sub-millisecond full-text fuzzy search across thousands of copied records.
- **Background Clipboard Daemon**: Automatic text capture with SHA-256 deduplication and frequency tracking.
- **Global Shortcut Support**: `Super + V` launcher with GNOME `gsettings` script and Wayland portal support.
- **Smart Content Detection**: Automatic categorization of Code snippets, URLs, Emails, HEX/RGB Colors, and Plain Text.
- **Pinning & Favorites**: Ability to pin important items and keep them safe from history clearing.
- **Privacy Mode & Password Shield**: Single-click incognito mode, automatic detection of password manager clipboard hints and sensitive keys.
- **Keyboard-First Workflow**: Arrow key navigation, 1–9 numeric quick paste, `Enter` to paste, `P` to pin, and `Esc` to dismiss.
- **Auto-Retention Settings**: Configurable history limits (100, 500, 1000, 5000) and auto-delete timers.
- **Packaging Scripts**: Standalone `.deb` and `.AppImage` build tools for Ubuntu 22.04, 24.04, and 26.04.
